# EveryVideo

동영상을 재생하고, 구간을 잘라 저장하고, 화면을 캡쳐하는 안드로이드 동영상 재생기입니다.

## 기능

| 기능 | 내용 |
|---|---|
| 다양한 포맷 재생 | Media3 ExoPlayer + FFmpeg 오디오 디코더. MP4, MKV, WebM, AVI, MOV, FLV, TS/M2TS, MPEG, OGG, HLS(m3u8), DASH, RTSP 등. AC3·DTS·TrueHD 같은 기기 미지원 오디오도 재생 |
| 재생 도구 | 재생 속도(0.25~4배), 구간반복(A-B), 한 곡/전체 반복, 밝기(왼쪽 위아래 밀기), 볼륨(오른쪽 위아래 밀기, 마우스 휠), 좌우 밀어 탐색, 두 번 눌러 10초 이동, 화면 비율, 음성·자막 트랙 선택, 화면 잠금, 이어서 재생, 작은 창(PIP) |
| 캡쳐 / 구간 저장 | 현재 화면을 PNG 로 저장(사진/EveryVideo), 지정 구간을 MP4 로 저장(동영상/EveryVideo). 구간반복 A-B 를 지정해 두면 자동으로 채워짐 |
| 전체화면 | 전체화면 전환, 영상 비율에 맞춘 자동 가로/세로 회전, 수동 회전 |
| 구글 드라이브 / FTP / SMB | 파일 선택기의 Google Drive 에서 바로 스트리밍, 공유 링크 붙여넣어 바로 재생, FTP·SMB(윈도우 공유 폴더) 서버 등록 후 폴더 탐색·스트리밍 |
| 탐색 미리보기 | 시간 막대를 끌거나 마우스를 올리면 해당 시점의 작은 미리보기 화면 표시 (원격 파일 포함) |
| 이어붙이기 | 여러 동영상을 순서대로 하나의 MP4 로 합치기, 결과 해상도 선택 |
| 화면 녹화 | 안드로이드 MediaProjection 으로 화면 녹화(마이크 소리 선택), 알림에서 중지 |
| 즐겨찾기 | 재생 중 특정 시점을 메모와 함께 즐겨찾기, 시간 막대에 표시, 다시 열면 목록에서 바로 이동, 전체 즐겨찾기 모음 화면 |

## 설치

[Releases](../../releases) 에서 최신 `EveryVideo-x.y.z.apk` 를 내려받아 설치합니다.

## 빌드 / 릴리스

- `main` 에 push 하면 GitHub Actions 가 APK 를 빌드해 Artifacts 로 올립니다.
- `VERSION` 파일의 버전을 올려 `main` 에 push 하면, 그 버전이 아직 릴리스되지 않았을 때 자동으로 `v버전` 태그와 GitHub Release 를 만들고 APK 를 첨부합니다. `v*` 태그를 직접 push 해도 릴리스됩니다.
- 서명 키는 저장소 Secrets(`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`)로 넣습니다. 없으면 빌드마다 새 디버그 키로 서명되어, 새 버전을 설치할 때 기존 앱을 지우고 다시 설치해야 합니다. 서명 키를 등록하면 그 뒤로는 덮어쓰기 업데이트가 됩니다.

로컬 빌드: `./gradlew assembleRelease` (JDK 17, Android SDK 35 필요)

## 참고

- 구글 드라이브 공유 링크 재생은 "링크가 있는 모든 사용자" 로 공유된 파일에서 동작합니다. 내 드라이브의 비공개 파일은 파일 선택기의 Google Drive 항목으로 여세요.
- 화면 녹화는 안드로이드 표준 화면 녹화 기능을 씁니다. 앱이 보안 화면(FLAG_SECURE)으로 보호한 내용은 시스템 정책에 따라 검게 녹화되며, 이를 우회하는 기능은 넣지 않았습니다.
- 영상 코덱(H.264/H.265/VP9/AV1 등)은 기기 하드웨어 디코더를 사용하므로 기기에 따라 지원 범위가 다를 수 있습니다.
